# lgcp_wildefires_Portugal_thesis

The main objective of the work was to develop LGCP models in order to characterize the spatial pattern of occurrence of forest fires in Portugal.

We work with a dataset that contains information about forest fires in mainland Portugal, in the year 2020 (.xlsx available with the name "2020_1") . 
We define nine LGCP models to analyze the pattern of fire occurrence, consedering the effect of some covariates. 
The code used is available in the file "code_LGCP".
